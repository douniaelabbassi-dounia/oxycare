# OxyCare – Oxygène Excellence Assistance

Site vitrine d'OxyCare (anciennement Oxygène Excellence Assistance) : assistance administrative (CNSS, AMO, Moukataâ), accompagnement des seniors, logistique automobile et conciergerie à Agdal, Rabat.

Site en ligne : https://douniaelabbassi-dounia.github.io/oxycare/

- Site statique (HTML, CSS, JavaScript), sans dépendances
- Bilingue français / arabe
- Coordonnées modifiables dans le bloc `CONFIG` de `js/main.js`
